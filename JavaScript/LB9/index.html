Використання JavaScript Promise API

Завдання 4. Порівняння чисел

Введіть два числа. Promise порівняє їх через 1 секунду. Якщо числа рівні, Promise буде відхилено.

Завдання 5. Сума випадкових чисел

Три Promise запускаються одночасно та повертають випадкові числа від 1 до 10 через 1, 2 та 3 секунди. Promise.all очікує на всі результати, після чого обчислюється сума.
